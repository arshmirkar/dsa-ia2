Speaker 1 — Core Setup & Quad-Tree Insertion (Person 2's Part)

"Hello everyone. Today we are presenting our Smart Agriculture Spatial Indexing & Irrigation Advisory System written in C (dsaia2.c). I implemented the Quad-Tree spatial data structure and plot insertion (QuadNode, Boundary, and insert_plot). We initialize our map centered at (50, 50) with halfDim = 50, covering 0 to 100. When a plot is inserted into an empty leaf node (hasPlot == 0 && NW == NULL), it is stored directly. As soon as a second plot enters the same region—like Plots 1001 and 1003 in the Southwest quadrant—the node subdivides its halfDim by 2.0 into 4 child quadrants (NW, NE, SW, SE) and pushes the plots down recursively."

Speaker 2 — Spatial Region Search & Pruning (Person 3's Part)

"Thank you. I implemented the Spatial Region Search (intersect and search_region). Instead of scanning every farm plot in a flat list ($O(N)$), our search_region() function checks whether a quadrant's boundary overlaps the target searchArea using intersect(). If a quadrant does not intersect, the entire subtree is pruned immediately. On the dashboard, you can see the exact count of Visited vs. Pruned QuadNodes and watch matching plots highlight in real time."

Speaker 3 — Priority Queue Irrigation Advisories (Person 1's Part)

"Finally, I implemented the Irrigation Advisory Priority Queue (PriorityQueue, add_advisory, and get_next_advisory). Each farm plot experiencing moisture stress is enqueued with an urgency level from 1 to 10. When get_next_advisory() is called, it scans pq->queue to find maxIdx—the plot with the highest urgency—dispatches water to that plot first, and replaces pq->queue[maxIdx] with the last element pq->queue[pq->size - 1] for $O(1)$ removal."
